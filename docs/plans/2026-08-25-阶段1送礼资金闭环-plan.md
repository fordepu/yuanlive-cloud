# 阶段 1 送礼资金闭环 Plan

> **供执行智能体使用：** 按任务逐项实施并在每个任务完成后执行对应测试；任务使用复选框跟踪。

**目标：** 实现可测试的模拟充值、送钱记账、可靠事件投递、直播展示、查询与对账闭环。

**依据：** [PRD](../prd/2026-08-25-阶段1送礼资金闭环-prd.md) 与 [SPEC](../specs/2026-08-25-阶段1送礼资金闭环-spec.md)。

**全局约束：** 在 `dev` 分支开发；金额用 `long`；所有钱包核心表的 `id` 使用 CosId 雪花 `BIGINT`，实体使用 `@CosId` 和 `IdType.INPUT`，DDL 禁止 `AUTO_INCREMENT`，并引入 `cosid-mybatis` 插件；资金事务使用本地 `@Transactional`；资金事件使用 Outbox、Inbox、手动 ACK、重试和死信；复杂事务和消息可靠性代码增加简体中文注释。使用 `-am -Dtest=...` 执行聚合测试时附带 `-Dsurefire.failIfNoSpecifiedTests=false`，使没有该测试类的上游模块不阻断目标模块测试。
